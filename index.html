WHAT YOU CAN CHECK

電話する前に分けておくこと

電話や写真見積もりの前に、自治体で出す物、施設へ持ち込む物、業者に運び出してもらう物を分けます。ここが分かれていると、当日の追加作業を減らしやすくなります。

自治体で出せる物

袋に入る生活ごみや資源ごみ、自分で外へ出せる粗大ごみは、まず自治体の分別表と収集日を確認します。退去日が近いときは、収集日まで待てる物と待てない物を分けておきます。

自己搬入できる物

車で運べる量なら、清掃工場やクリーンセンターへ持ち込める地域もあります。受付日、予約、本人確認、車両条件、持ち込めない品目は地域で違うため、屋内搬出とは別に見ておきます。

業者へ任せる物

大型家具、2階からの搬出、分別前の大量家財、物置や庭まわりは、人手と車両が必要になりやすい部分です。搬出経路、駐車位置、階段の有無まで見積もり時に伝えます。

立会いなしの確認

遠方から進める場合は、鍵の受け渡し、処分前に確認する写真、探してほしい物、返送する物、支払い方法を先に決めます。作業後の写真だけでなく、捨てる前に見たい物も共有しておきます。

空き家・実家じまい

売却や解体の前は、権利書、固定資産関係の書類、保険、契約書、通帳、仏壇、写真を処分品に混ぜないようにします。室内だけでなく、物置、庭、車庫、納屋も見ておくと安心です。

SITE GUIDE

業者へ相談する前に、ここだけ先に確認

最初から業者名や金額だけを比べると、何が含まれている見積もりなのか分かりにくくなります。先に地域のルール、家の状況、業者へ頼む範囲を分けると、見積もりの差を見やすくなります。

1. 地域の出し方を先に見る

粗大ごみ、自己搬入、処理施設、家電4品目、収集できない品目は市区町村ごとに違います。地域ページでは、公式情報で確認できる範囲を先にまとめています。

2. 自分で出せる物と運び出してもらう物を分ける

玄関前や指定場所まで出せる物は、行政収集で済む場合があります。タンス、食器棚、ベッド、仏壇、金庫、物置、階段作業は、業者へ頼む作業として分けます。

3. 同じ条件で見積もりを比べる

同じ間取りでも、荷物の量、階数、エレベーター、駐車位置、買取、供養、貴重品探索の有無で金額は変わります。写真と作業範囲をそろえて相談します。

TROUBLE PREVENTION

あとで困らないための確認点

安さだけで決める前に、見積書、処分ルート、追加料金、買取や供養の扱いを確認します。ここが曖昧なままだと、当日の追加請求や処分方法の行き違いにつながりやすくなります。

見積書で見るところ

  • 作業人数、車両、搬出階、階段作業、養生の有無
  • 処分費、家電リサイクル、買取、供養、探索の扱い
  • 追加料金が発生する条件と、キャンセル時の扱い

許可・資格の見方

  • 古物商許可は買取に関する確認材料です
  • 一般廃棄物の収集運搬は自治体ルールの確認が必要です
  • 遺品整理士などの資格は、作業姿勢を見る材料として確認します

通常ごみと分ける品目

  • テレビ、冷蔵庫、洗濯機、エアコンなど家電4品目
  • パソコン、リチウムイオン電池、消火器、灯油、塗料、農薬
  • 金庫、タイヤ、建築廃材、事業系ごみ、仏壇・写真など供養品

立会いなし・遠方対応

  • 鍵の受け渡し方法、作業前後の写真報告を決める
  • 残す品、返送品、探す書類、貴重品探索の範囲を伝える
  • 処分前確認が必要な品を、部屋ごとに分けておく

自治体公式情報や確認できた事実をもとに、粗大ごみ、自己搬入、屋内搬出、処理困難物を分けて掲載しています。行政手続きや処分可否は、各自治体・処理施設・公式窓口の最新情報を必ず確認してください。

COMMON CASES

よくある相談の場面

退去前の片付け、施設入居前の生前整理、相続後の実家じまい、遠方からの立会いなし作業など、実際に相談前で止まりやすい場面をまとめています。

賃貸退去前の1K整理

退去日と鍵返却が決まっている部屋では、粗大ごみ収集日を待てないことがあります。ベッド、冷蔵庫、洗濯機、机、布団を行政で出す物と屋内搬出が必要な物に分け、管理会社の立会い時間も確認します。

施設入居前の生前整理

入居先へ持ち込める量を先に確認し、衣類、薬、保険証、診察券、介護用品を別箱にします。写真や手紙、仏壇まわりは本人と家族で判断し、残る大型家具は退去日から逆算して整理します。

相続後の実家じまい

売却・解体を急ぐ前に、通帳、印鑑、権利書、固定資産、保険証券、契約書を探します。室内だけでなく、物置、庭、車庫、仏壇、写真まで確認し、親族へ返す物と処分する物を分けます。

遠方家族の立会いなし整理

現地へ何度も行けない場合は、鍵の受け渡し、処分前写真、作業後写真、返送品、買取希望品、供養品を先に決めます。追加作業が出た時に誰が承認するかも決めておくと進行が止まりにくくなります。

LOCAL RULES

地域ページで先に見ること

同じ片付けでも、粗大ごみの予約、持ち込み施設、福祉相談、空き家相談は市区町村で違います。作業場所のページを先に見ると、自治体へ確認することと業者へ頼むことを分けやすくなります。

  • 粗大ごみは、電話予約、ネット申込、処理券、戸別収集、指定場所への排出など、自治体ごとに流れが違います。

BEFORE ESTIMATE

見積もり前に、ここまで分けておくと話が早いです

家の中を全部片付ける相談でも、実際には「残す」「探す」「行政で出す」「業者へ任せる」「処分前に確認する」に分かれます。ここを先に決めておくと、見積もりの説明が短くなり、当日の判断ミスも減ります。

残すもの通帳、権利書、保険証券、印鑑、契約書、写真、手紙、形見分け予定品、本人が使う薬や介護用品。段ボールや袋で「残す」と分かるように分けます。
探してほしいもの現金、貴金属、年金・保険関係書類、不動産書類、車の書類、鍵、スマートフォン、パソコン、暗号資産やネット銀行の手がかり。探索場所を押入れ、引き出し、仏壇まわりなど具体的に伝えます。
行政で出すもの少量で自力搬出できる家具、布団、小型家電、衣類、資源ごみなど。地域ページで粗大ごみ受付、処理券、点数制限、排出場所、収集日を確認します。
業者へ任せるもの屋内搬出が必要なタンス、食器棚、ベッド、冷蔵庫まわり、仏壇、金庫、物置、庭まわり、大量の生活用品。階段、エレベーター、駐車位置、養生の要否も一緒に伝えます。
別確認するもの家電4品目、パソコン、リチウムイオン電池、消火器、灯油、塗料、農薬、タイヤ、建築廃材、事業系ごみ、供養希望品。普通ごみや粗大ごみに混ぜず、公式窓口や専門回収を確認します。
ESTIMATE DEPTH

費用が変わる理由を、間取りだけで判断しない

料金表は入口として便利ですが、最終金額は部屋数だけでは決まりません。家財量、搬出条件、処分品、確認作業の有無を同じ条件で伝えると、比較しやすくなります。

搬出条件で変わるもの

  • エレベーターなし、階段幅が狭い、曲がり角が多い
  • 建物前に車両を停められない、台車移動が長い
  • 管理会社への届出、共用部養生、搬出時間の制限がある

  • 物置、庭木、倉庫、車庫、農具、工具、屋外用品

FAQ

よくある質問

このサイトは何を確認するためのサイトですか？

遺品整理や生前整理を頼む前に、地域の行政ルール、料金が変わる条件、写真見積もりで伝えること、家族で決めることを整理するためのサイトです。地域ページでは自治体確認、コラムでは見積もり前の判断材料を確認できます。

自治体公式情報はどこで確認すればいいですか？

各地域ページの行政窓口、粗大ごみ、自己搬入、空き家・住まい相談の欄に公式リンクを載せています。制度名、受付日、料金、対象品目は変わることがあるため、作業日を決める前に公式ページで最新条件を確認してください。

市区町村ページで見る内容は？

地域ページでは、役所窓口、粗大ごみ・大型ごみ、自己搬入先、処理困難物、高齢者支援、空き家相談、見積もり前に業者へ伝える内容を確認します。

立会いなしでも相談できますか？

鍵の受け渡し、写真報告、オンライン確認、返送品の扱いを決めれば、遠方家族でも進めやすくなります。

行政ごみと業者作業はどう分けますか？

少量で自力搬出できる物は行政、大型家具の屋内搬出や大量家財、供養品、貴重品探索は業者作業として分けます。

安い業者を選べば大丈夫ですか？

金額だけでは判断しない方が安全です。作業人数、搬出階、車両、処分費、家電リサイクル、追加料金の条件、買取や供養の扱いを見積書で確認してください。

古物商許可があれば不用品をすべて回収できますか？

古物商許可は買取に関する確認材料です。家庭ごみや粗大ごみの収集運搬は自治体ルールと別に確認が必要です。行政収集、自己搬入、業者作業を分けて相談してください。

家電4品目やパソコンは粗大ごみで出せますか？

テレビ、冷蔵庫、洗濯機、エアコンなどの家電4品目、パソコン、リチウムイオン電池、消火器、灯油、塗料などは通常ごみと別確認になることが多い品目です。地域ページと公式窓口で扱いを確認します。

写真見積もりでは何を撮ればいいですか？

各部屋の全体、収納の中、玄関、廊下、階段、エレベーター、建物入口、駐車位置、物置、庭、仏壇、金庫を撮ると、作業量と搬出条件を伝えやすくなります。

家族で先に決めることはありますか？

残す品、探す書類、形見分け、返送品、供養品、買取候補、処分前確認が必要な品を決めます。判断者と連絡方法を決めておくと、作業当日に迷いにくくなります。

退去期限が近い場合はどう進めますか？

行政収集で間に合うもの、自己搬入を検討するもの、業者が屋内搬出するものを先に分けます。鍵返却日、管理会社の搬出ルール、駐車位置、エレベーター予約も同時に確認してください。
